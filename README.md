# Threads word bot

A short, just-for-fun project that posts German words from a filtered dictionary to Threads. It picks a word from `words.txt` based on the time, moving to the next one every 30 minutes.

It's triggered through the cron-job website because GitHub Workflows' internal cron doesn't work for this project.
